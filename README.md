# 🇧🇷 Português

## Sobre este repositório

Este repositório registra minha jornada acadêmica durante a **Fase 05** do curso de **Análise e Desenvolvimento de Sistemas da FIAP**, voltada à linguagem **Java** e à **Programação Orientada a Objetos**.

O objetivo não é apenas armazenar exercícios concluídos. Este espaço funciona como uma **linha do tempo prática da minha evolução**, mostrando como cada atividade contribui para fortalecer minha lógica, ampliar minha autonomia e transformar conceitos estudados em código funcional.

Neste início, estou me adaptando à sintaxe do Java, às convenções da linguagem e ao processo de compilar, executar, testar e corrigir programas. Ao longo da jornada, essa base será utilizada para avançar de soluções estruturadas para uma forma mais organizada de analisar e modelar sistemas.

> **Mais do que aprender uma nova linguagem, esta fase representa a construção de uma nova maneira de pensar software.**

## Construindo um novo paradigma

A transição para a **Programação Orientada a Objetos** envolve mudar gradualmente a forma de observar um problema.

Antes de pensar apenas em uma sequência de instruções, a proposta passa a ser identificar:

- quais elementos fazem parte do domínio;
- quais dados caracterizam cada elemento;
- quais comportamentos pertencem a cada objeto;
- quais responsabilidades devem ser separadas;
- como os objetos podem colaborar sem criar dependências desnecessárias;
- como proteger estados internos e controlar o acesso aos dados;
- como reutilizar estruturas e especializar comportamentos;
- como preparar o programa para mudanças, erros e novos requisitos.

Essa evolução será construída passo a passo. O repositório mostrará esse processo de forma autêntica: desde os primeiros contatos com a sintaxe até a criação de soluções orientadas a objetos mais organizadas.

# 🇬🇧 English

## About this repository

This repository documents my academic journey throughout **Phase 05** of FIAP's **Systems Analysis and Development** program, focused on **Java** and **Object-Oriented Programming**.

The goal is not simply to store completed exercises. This space works as a **practical timeline of my development**, showing how each activity strengthens my programming logic, increases my autonomy, and transforms studied concepts into working code.

At the beginning of this journey, I am adapting to Java syntax, language conventions, and the process of compiling, running, testing, and fixing programs. As the journey progresses, this foundation will support the transition from structured solutions to a more organized way of analyzing and modeling software systems.

## Building a new paradigm

The transition to **Object-Oriented Programming** gradually changes how a problem is observed and modeled.

Instead of thinking only about a sequence of instructions, the process begins to identify:

- which elements belong to the problem domain;
- which data describes each element;
- which behaviors belong to each object;
- which responsibilities should remain separate;
- how objects can collaborate without unnecessary dependencies;
- how internal state can be protected and data access controlled;
- how structures can be reused and behaviors specialized;
- how software can be prepared for changes, errors, and new requirements.

This development will happen one step at a time. The repository will document the process authentically — from the first contact with Java syntax to the creation of more organized object-oriented solutions.
